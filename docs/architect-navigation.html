Core Subsystem

Navigation

Tab bars, pills, sidebars, steppers, and Livewire workspace tabs. All driven from the same fluent NavigatorBuilder.

Navigator Types

FactoryStyleUse when
Architect::tabs()Underline pill tabsSection-level navigation within a page
Architect::navTabs()Alias for tabs()
Architect::pills()Filled pill buttonsCompact selection with few options
Architect::buttons()Button groupView-mode toggles (e.g. List / Grid)
Architect::stepper()Numbered step indicatorsMulti-step wizard progress
Architect::sidebar()Vertical sidebar linksModule-level navigation
Architect::dropdown()Dropdown menuOverflow nav or context menus
Architect::toolbar()Contextual toolbarSee Toolbar docs
Architect::workspaceTabs(key)Livewire multi-tab workspaceConcurrent records (inbox, case workers)

Link-Based Navigators

Link navigators produce static <a href> tabs rendered server-side. No Livewire required.

use Entelechy\Architect\Facades\Architect;
use Entelechy\Architect\Navigator\Items\Tab;

$nav = Architect::tabs()
    ->tab(Tab::make('Overview')->href('/members')->default())
    ->tab(Tab::make('Activity')->href('/members/activity'))
    ->tab(Tab::make('Finance')->href('/members/finance'))
    ->build();

// In a table definition:
$this->navigator($nav);

Workspace Tabs (Livewire)

Workspace tabs host multiple Livewire components simultaneously below a shared topbar. Alpine x-show handles visibility with zero server round-trips. Ideal for inbox/case-worker UIs where users keep multiple records open.

use Entelechy\Architect\Facades\Architect;
use Entelechy\Architect\Navigator\Items\PinnedTab;
use Entelechy\Architect\Navigator\Items\DynamicTabType;

class MembersTabsDefinition
{
    public static function build(): WorkspaceTabsDefinition
    {
        return Architect::workspaceTabs('members-workspace')
            ->persist()
            ->maxTabs(8)
            ->pinnedTab(
                PinnedTab::make('All Members')
                    ->icon('fas fa-users')
                    ->component(\App\Modules\Members\Livewire\MembersList::class)
            )
            ->dynamicTab(
                DynamicTabType::make('member')
                    ->component(\App\Modules\Members\Livewire\MemberDetail::class)
                    ->icon('fas fa-user')
                    ->labelResolver(fn($props) => 'Member #' . $props['id'])
            )
            ->showOverflowPopover()
            ->showRecentlyClosed(5)
            ->enableSwitcherPalette()
            ->build();
    }
}

Workspace Builder API

MethodDescription
Architect::workspaceTabs(string $key)Start a workspace. Key identifies the Livewire component and LocalStorage namespace.
persist(bool)Persist open tabs in LocalStorage across page loads.
maxTabs(int)Maximum number of simultaneously open tabs.
pinnedTab(PinnedTab)Add a fixed tab that is always present (cannot be closed).
dynamicTab(DynamicTabType)Register a dynamic tab type (opened programmatically by the user).
showOverflowPopover(bool)Show a +N overflow popover when tabs exceed the available width.
showRecentlyClosed(int $max)Show a "Recently closed" list in the overflow popover.
enableSwitcherPalette(bool)Enable ⌘K palette for tab switching.
notifyStaleRecords(bool)Emit a warning when a dynamic tab's record has been modified since it was opened.

Rendering Workspace Tabs

<!-- Pass the FQCN string — the component rebuilds fresh on each request -->
<x-architect definition-class="\App\Modules\Members\Components\Tabs\MembersTabsDefinition" />

<!-- Backward-compatible alias: -->
<x-module-tabs definition-class="\App\Modules\Members\Components\Tabs\MembersTabsDefinition" />

SPA Tabs

Link-based navigators can operate in SPA mode using ->spa() on the builder. In this mode Alpine handles tab switching client-side without a page reload. Tab panes are rendered with ->architect(), ->component(), or ->view() on each Tab.

Architect::tabs()
    ->spa()
    ->tab(
        Tab::make('Details')
            ->withSlug('details')
            ->component(\App\Modules\Members\Livewire\MemberDetails::class, ['id' => $id])
    )
    ->tab(
        Tab::make('Finance')
            ->withSlug('finance')
            ->architect(\App\Modules\Finance\Components\Tables\MemberTransactionsTableDefinition::class)
    )
    ->build();
