Getting Started

Quick Start

Get Architect installed and ship your first CRUD table in under 10 minutes.

Requirements

DependencyVersion
PHP8.2 or higher
Laravel10, 11, or 13
Livewire3.x
Alpine.js3.x

Installation

1. Install the package

composer require entelechy/architect

2. Publish assets & config

# Publish config and Blade stubs
php artisan vendor:publish --tag=architect-config
php artisan vendor:publish --tag=architect-views

# Publish CSS/JS assets to public/vendor/architect/
php artisan vendor:publish --tag=architect-assets

3. Add to your base layout

<!-- In <head> -->
@architectStyles

<!-- Before </body> -->
@architectScripts
<livewire:architect-toast-manager />

4. Register the facade (optional)

Architect auto-registers the Architect alias in Laravel. You can import the facade explicitly if your IDE prefers it:

use Entelechy\Architect\Facades\Architect;

Your First CRUD Table

1. Generate the definition class

php artisan make:architect-table Members --model=Member --module=Members

This creates:

  • app/Modules/Members/Components/Tables/MembersTableDefinition.php — table config
  • app/Modules/Members/Models/MemberDataModel.php — Architect data model
  • database/migrations/customer/YYYY_MM_DD_000000_create_members_table.php — migration stub

2. Define your columns

use Entelechy\Architect\Tables\ArchitectTableDefinition;
use Entelechy\Architect\Tables\Columns\TextColumn;
use Entelechy\Architect\Tables\Columns\BadgeColumn;
use Entelechy\Architect\Tables\Columns\DateColumn;

class MembersTableDefinition extends ArchitectTableDefinition
{
    public function definition(): static
    {
        return $this
            ->title('Members')
            ->dataModel(MemberDataModel::class)
            ->columns([
                TextColumn::make('name')->label('Name')->sortable()->searchable(),
                TextColumn::make('email')->label('Email')->searchable(),
                BadgeColumn::make('status')->label('Status')->sortable(),
                DateColumn::make('created_at')->label('Joined')->sortable(),
            ]);
    }
}

3. Add a route

// routes/web.php or app/Modules/Members/Routes/web.php
Route::get('/members', [MembersController::class, 'index'])->name('members.index');

4. Render in your controller & view

// MembersController.php
public function index(): View
{
    return view('members.index', [
        'definition' => (new MembersTableDefinition())->definition(),
    ]);
}

// resources/views/members/index.blade.php
<x-architect :definition="$definition" />
That's it. Architect renders the table, pagination, search, column sort, and the full create / edit / view / delete modal flow automatically.
