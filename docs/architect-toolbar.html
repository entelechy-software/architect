Core Subsystem

Toolbar

Contextual action bars with buttons, dropdowns, search, badge indicators, radio groups, and separators.

Overview

Toolbars are rendered by ToolbarEngine and configured via ToolbarBuilder. Items flow left to right; ->right() items are pushed to the trailing edge.

use Entelechy\Architect\Facades\Architect;
use Entelechy\Architect\Toolbar\Items\ToolbarButton;
use Entelechy\Architect\Toolbar\Items\ToolbarDropdown;

$toolbar = Architect::toolbar()
    ->item(
        ToolbarButton::make('add-member')
            ->label('Add Member')
            ->icon('fas fa-plus')
            ->color('primary')
            ->filled()
            ->wireClick('openCreateModal')
    )
    ->right(
        ToolbarButton::make('export')
            ->label('Export')
            ->icon('fas fa-download')
            ->href(route('members.export'))
    )
    ->build();
<x-architect :definition="$toolbar" />

ToolbarBuilder API

MethodDescription
Architect::toolbar()Start building a toolbar.
key(string)Unique key for the toolbar (used for Livewire event scoping).
item(ToolbarItem)Add an item to the left side.
right(ToolbarItem)Add an item pinned to the right side.
bind(string $targetKey)Bind this toolbar to a table or other component by key. Sends toolbar events to the bound component.
size(string)Toolbar height: 'sm'|'md' (default) |'lg'.
bordered(bool)Add a border below the toolbar.
sticky(bool)Stick the toolbar to the top of the viewport on scroll.
build()Returns ArchitectToolbarDefinition.

Toolbar Items

ToolbarButton

ToolbarButton::make('create')
    ->label('New Record')
    ->icon('fas fa-plus')
    ->color('primary')         // 'primary'|'secondary'|'danger'|'success'|'warning'
    ->filled()                 // solid background (outlined by default)
    ->wireClick('openModal')   // Livewire wire:click expression
    ->dispatch('record-created', ['type' => 'member'])  // dispatch a browser event
    ->badge('3', 'danger')     // badge pill on the button
    ->tooltip('Create a new record')
    ->permission('members.create')
    ->disabled(false)
    ->newWindow(false);

ToolbarDropdown

use Entelechy\Architect\Toolbar\Items\ToolbarDropdown;
use Entelechy\Architect\Toolbar\Items\Dropdown\DropdownAction;
use Entelechy\Architect\Toolbar\Items\Dropdown\DropdownSeparator;
use Entelechy\Architect\Toolbar\Items\Dropdown\DropdownLinkGroup;

ToolbarDropdown::make('actions')
    ->label('More Actions')
    ->icon('fas fa-ellipsis-v')
    ->item(DropdownAction::make('archive')->label('Archive')->wireClick('archive'))
    ->item(DropdownSeparator::make())
    ->item(DropdownAction::make('export')->label('Export CSV')->href(route('export')));

Dropdown Item Types

ClassDescription
DropdownActionClickable action with optional wireClick, href, or dispatch.
DropdownLinkGroupGroup of related links under a section heading.
DropdownRadioGroupRadio group for mutually-exclusive selections.
DropdownCheckboxToggleable checkbox option.
DropdownToggleBinary toggle switch.
DropdownTextInputInline text input (e.g. rename in place).
DropdownSubmenuNested sub-menu.
DropdownSeparatorVisual horizontal rule.

Other Toolbar Items

ClassDescription
ToolbarSearchInline search input that dispatches a Livewire event on input.
ToolbarRadioGroupHorizontal radio group (e.g. "View: List / Grid").
ToolbarButtonGroupGrouped buttons sharing a single border radius (split-button style).
ToolbarBadgeStatic badge/chip for status indicators.
ToolbarSeparatorVertical divider between toolbar items.
ToolbarSpacerFlex spacer — pushes subsequent items to the right.
