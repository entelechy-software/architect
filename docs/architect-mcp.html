MCP Tools

Five Model Context Protocol tools let your AI assistant scaffold, inspect, and understand your Architect definitions without reading documentation.

Overview

Architect ships five MCP tools in Entelechy\Architect\Mcp\Tools\. When registered with an MCP server, AI tools (GitHub Copilot, Claude, etc.) can use them to:

  • List existing Architect definitions in your project
  • Inspect a specific definition and understand its columns, fields, and permissions
  • List all available field types and their methods
  • Scaffold a new table definition with columns, fields, and a migration stub
  • Generate a FormBuilder stub from a field specification

Requirements

The MCP tools require the laravel/mcp package to be installed in your host application:

composer require laravel/mcp

The Architect package itself does not require laravel/mcp — it is listed as a suggestion in composer.json so the tools are available if you have the MCP server installed.

Registration

Register the tools in your host application's MCP server class (the class that extends Laravel\Mcp\Server):

use Laravel\Mcp\Server;
use Entelechy\Architect\Mcp\Tools\ArchitectListModulesTool;
use Entelechy\Architect\Mcp\Tools\ArchitectScaffoldTableTool;
use Entelechy\Architect\Mcp\Tools\ArchitectListFieldsTool;
use Entelechy\Architect\Mcp\Tools\ArchitectInspectDefinitionTool;
use Entelechy\Architect\Mcp\Tools\ArchitectGenerateFormTool;

class YourMcpServer extends Server
{
    protected array $tools = [
        // ... your existing tools ...
        ArchitectListModulesTool::class,
        ArchitectScaffoldTableTool::class,
        ArchitectListFieldsTool::class,
        ArchitectInspectDefinitionTool::class,
        ArchitectGenerateFormTool::class,
    ];
}

Tools Reference

architect_list_modules

Class: ArchitectListModulesTool

Scans app/Modules/ recursively for Architect definition classes and returns them grouped by type.

InputTypeDescription
typestring (optional)Filter by type: 'TableDefinition'|'FormDefinition'|'ContentDefinition'|'TabsDefinition'|'Navigator'.

Returns an array of objects with class, type, module, file keys.

Example AI prompt: "What Architect tables do we have in the Members module?"

architect_inspect_definition

Class: ArchitectInspectDefinitionTool

Reflects on a definition class and returns its column list, field list, and permissions. Security: only allows App\ or Entelechy\ namespaces.

InputTypeRequiredDescription
classstringyesFQCN of the definition class (e.g. App\Modules\Members\Components\Tables\MembersTableDefinition).

Example AI prompt: "Inspect the MembersTableDefinition and tell me what columns it has."

architect_list_fields

Class: ArchitectListFieldsTool

Returns a catalogue of all 27 Architect form field types with class name, input type, description, and key methods.

InputTypeDescription
filterstring (optional)Filter by keyword (e.g. 'date', 'select', 'text').

Example AI prompt: "What date-related field types does Architect support?"

architect_scaffold_table

Class: ArchitectScaffoldTableTool

Generates a *TableDefinition PHP class, a *DataModel class, and a migration stub from a field specification.

InputTypeRequiredDescription
modulestringyesModule name (e.g. Members).
entitystringyesEntity name in PascalCase (e.g. Member).
table_namestringyesDatabase table name (snake_case).
fieldsarrayyesArray of { name, type, label, required } field specs.

Returns a { table_definition, data_model, migration } object with PHP source for each file.

Example AI prompt: "Scaffold a Members table with fields: name (text, required), email (email, required), status (select)."

architect_generate_form

Class: ArchitectGenerateFormTool

Generates a FormBuilder PHP stub from a field specification.

InputTypeRequiredDescription
form_keystringyesForm identifier in kebab-case (e.g. member-form).
class_namestringyesPHP class name for the form definition.
namespacestringyesPHP namespace (e.g. App\Modules\Members\Forms).
titlestringyesForm heading.
save_routestringyesNamed route for form submission.
fieldsarrayyesArray of { name, type, label, required } field specs.

Example AI prompt: "Generate a FormBuilder stub for creating a new event with fields: title, start_date, end_date, capacity."

Security Notes

ArchitectInspectDefinitionTool only allows reflecting on classes in the App\ or Entelechy\ namespaces. This prevents class loading arbitrary paths. The class string is validated before class_exists() is called.

All scaffold/generate tools return PHP source code as strings — they do not write files directly. The AI assistant (or user) decides where to save the output.
