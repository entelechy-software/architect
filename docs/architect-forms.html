Components & Forms

Form Controls

27 field types, a fluent FormBuilder, a WizardBuilder, conditional logic, autosave, and lifecycle hooks.

Package docs This page covers the Architect form system (Entelechy\Architect\Forms).

FormBuilder

use Entelechy\Architect\Forms\FormBuilder;
use Entelechy\Architect\Forms\Fields\TextField;
use Entelechy\Architect\Forms\Fields\SelectField;

$form = FormBuilder::make('member-form')
    ->title('New Member')
    ->saveRoute('members.store')
    ->fields([
        TextField::make('name')->label('Full Name')->required(),
        TextField::make('email')->label('Email')->type('email')->required(),
        SelectField::make('status')->label('Status')->options([
            'active'   => 'Active',
            'inactive' => 'Inactive',
        ]),
    ])
    ->build();

FormBuilder API

MethodDescription
FormBuilder::make(string $key)Static factory. Key is used for event scoping.
title(string)Form heading.
saveRoute(string)Named route POSTed on submit.
fields(array)Flat list of field objects (or mix with sections).
section(string $label, array $fields)Wrap fields in a labelled section.
grid(int $cols, array $fields)Lay fields out in a grid column layout.
autosave(int $debounceMs)Auto-save form data after N ms of inactivity.
onSaved(Closure)Callback invoked after the form is saved successfully.
build()Returns ArchitectFormDefinition.

WizardBuilder

Multi-step forms with optional per-step validation.

use Entelechy\Architect\Forms\WizardBuilder;

WizardBuilder::make('onboarding')
    ->step('Personal Details', [
        TextField::make('first_name')->required(),
        TextField::make('last_name')->required(),
    ])
    ->step('Contact', [
        TextField::make('email')->type('email')->required(),
        TextField::make('phone'),
    ])
    ->validateOnStep()
    ->saveRoute('onboarding.store')
    ->build();

Common Field API

All field classes share these base methods from Field:

TextField::make('name')
    ->label('Full Name')          // display label
    ->hint('Max 100 characters')  // helper text below field
    ->placeholder('John Smith')
    ->required(true)
    ->disabled(false)
    ->hidden(false)
    ->default('pending')
    ->rules('required|max:100')   // Laravel validation rules
    ->permission('members.edit_name')  // hide if user lacks this node
    ->visibleWhen('role', '=', 'admin');  // Alpine-driven conditional visibility
