Architect

The unified UI framework for Laravel admin panels — CRUD tables, form builders, navigation, dashboards, notifications, and AI tooling in a single composable API.

Quick Start → Core Concepts GitHub

What is Architect?

Architect is a Laravel package that provides a high-level builder API for common admin UI patterns. Instead of writing Blade templates, Alpine components, and Livewire wires by hand, you describe your interface in PHP and Architect renders it consistently.

It is built on top of Livewire 3 and Alpine.js 3, uses Tailwind-compatible utility classes, and is designed to work with any Laravel 10+ application.

Open source Architect is an open-source Laravel package released under the MIT licence. The namespace is Entelechy\Architect.
