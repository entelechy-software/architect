Components & Forms

Panels

Flexible dashboard panels: stats cards, charts, image carousels, quick forms, and embedded tables in a configurable grid layout.

Overview

Panels are rendered by the PanelEngine Livewire component and configured via DashboardBuilder. Each panel occupies a number of grid columns (1–12) and renders its own Blade partial.

use Entelechy\Architect\Facades\Architect;
use Entelechy\Architect\Panels\Panels\StatsPanel;
use Entelechy\Architect\Panels\Panels\ChartPanel;

$dashboard = Architect::dashboard()
    ->title('Membership Overview')
    ->columns(12)
    ->panel(StatsPanel::make('headline-stats')->span(12)->cards([...]))
    ->panel(ChartPanel::make('signups-trend')->span(8)->series(fn($range) => [...]))
    ->panel(StatsPanel::make('quick-metrics')->span(4)->cards([...]))
    ->build();
<x-architect :definition="$dashboard" />

DashboardBuilder API

MethodDescription
Architect::dashboard()Start building a dashboard.
title(string)Dashboard heading.
columns(int)Total grid columns (default: 12).
panel(Panel)Add a panel. Call multiple times for multiple panels.
gap(string)CSS gap value between panels (e.g. '1.5rem').
build()Returns ArchitectDashboardDefinition.

StatsPanel

use Entelechy\Architect\Panels\Panels\StatsPanel;
use Entelechy\Architect\Stats\Elements\MetricCard;

StatsPanel::make('key-metrics')
    ->span(12)
    ->columns(4)
    ->cards([
        MetricCard::make('Total Members')->value(fn() => Member::count()),
        MetricCard::make('Active Today')->value(fn() => Member::activeToday()->count())->trend(2.1),
    ]);
MethodDescription
StatsPanel::make(string $key)Static factory.
span(int)Grid columns to span.
columns(int)Inner grid columns for the metric cards.
cards(array|Closure)MetricCard[] or a closure returning them.
title(string)Optional section title above the cards.

ChartPanel

use Entelechy\Architect\Panels\Panels\ChartPanel;

ChartPanel::make('signup-trend')
    ->span(8)
    ->chartType('line')
    ->series(function ($range) {
        return [
            'labels' => collect($range->eachDay())->map->format('d M')->all(),
            'datasets' => [[
                'label' => 'New members',
                'data'  => collect($range->eachDay())
                            ->map(fn($day) => Member::whereDate('created_at', $day)->count())
                            ->all(),
            ]],
        ];
    });
MethodDescription
ChartPanel::make(string $key)Static factory.
span(int)Grid columns to span.
chartType(string)Chart.js type: 'line'|'bar'|'doughnut'|'pie'|'radar'.
series(Closure)Data provider. Receives a DateRange; returns Chart.js data object.
title(string)Panel heading.
height(int)Chart height in pixels.

ImageCarouselPanel

use Entelechy\Architect\Panels\Panels\ImageCarouselPanel;

ImageCarouselPanel::make('gallery')
    ->span(6)
    ->images(fn() => Photo::recent(10)->pluck('url')->all())
    ->captions(fn() => Photo::recent(10)->pluck('caption')->all())
    ->autoplay(5000);
MethodDescription
images(array|Closure)Array of image URLs.
captions(array|Closure)Optional captions (same index as images).
autoplay(int $ms)Auto-advance interval in milliseconds. 0 = no autoplay.
span(int)Grid columns to span.

QuickFormPanel

Embed a lightweight form directly in a dashboard panel.

use Entelechy\Architect\Panels\Panels\QuickFormPanel;
use Entelechy\Architect\Forms\Fields\TextField;
use Entelechy\Architect\Forms\Fields\SelectField;

QuickFormPanel::make('quick-add-member')
    ->span(4)
    ->title('Quick Add Member')
    ->fields([
        TextField::make('name')->required(),
        TextField::make('email')->type('email')->required(),
        SelectField::make('status')->options(['active' => 'Active']),
    ])
    ->saveRoute('members.store')
    ->successMessage('Member added.');

EmbeddedTablePanel

Embed an Architect table definition as a panel.

use Entelechy\Architect\Panels\Panels\EmbeddedTablePanel;

EmbeddedTablePanel::make('recent-members')
    ->span(12)
    ->title('Recently Joined Members')
    ->definitionClass(\App\Modules\Members\Components\Tables\MembersTableDefinition::class)
    ->limit(10);
