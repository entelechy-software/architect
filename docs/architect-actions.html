Actions

Row actions, header actions, bulk actions, and a Livewire ActionEngine — with built-in CRUD actions and confirmation dialogs.

Two Action Systems

Architect has two distinct action APIs:

  • Table-level actions (RowAction, HeaderAction, BulkAction) — configured on the TableBuilder and rendered inside the TableEngine.
  • ActionEngine actions (Action subclasses) — standalone action classes consumed by the ActionEngine Livewire component, used outside of tables (e.g. on detail pages).

Table Actions

RowAction

Appears in each row of the table (the "..." button or inline buttons).

use Entelechy\Architect\Table\Actions\RowAction;

RowAction::make('view-profile')
    ->label('View Profile')
    ->icon('fas fa-eye')
    ->url(fn($row) => route('members.show', $row['id']))
    ->newWindow()
    ->permission('members.view')
    ->confirm('Are you sure you want to delete this record?')
    ->visible(fn($row) => $row['status'] !== 'deleted');

HeaderAction

Appears in the table header (alongside the search bar and create button).

use Entelechy\Architect\Table\Actions\HeaderAction;

HeaderAction::make('import')
    ->label('Import CSV')
    ->icon('fas fa-file-upload')
    ->url(route('members.import'))
    ->color('secondary')
    ->permission('members.import');

Bulk Actions

use Entelechy\Architect\Table\Actions\BulkDeleteAction;
use Entelechy\Architect\Table\Actions\BulkArchiveAction;
use Entelechy\Architect\Table\Actions\BulkExportAction;

$this->bulkDelete(reasonRequired: false)
     ->bulkActions([
         BulkArchiveAction::make(),
         BulkExportAction::make(['csv', 'xlsx']),
     ]);
ClassDescription
BulkDeleteActionDelete selected rows.
BulkArchiveActionSoft-delete (archive) selected rows.
BulkRestoreActionRestore archived rows.
BulkCopyActionDuplicate selected rows.
BulkEmailActionSend a bulk email to selected rows (requires email field).
BulkStatusActionSet a status field on selected rows.
BulkExportActionExport selected rows to CSV or XLSX.

ActionEngine Actions

Standalone action classes used outside of tables — for detail pages, slide-overs, and workspace contexts.

Action Base Class API

use Entelechy\Architect\Actions\Actions\Action;

class ArchiveMemberAction extends Action
{
    public function label(string $label): static { return parent::label('Archive'); }

    // Actions are configured via the static builder pattern:
    public static function make(): static
    {
        return (new static)
            ->label('Archive Member')
            ->icon('fas fa-archive')
            ->color('warning')
            ->requiresConfirmation('Archive this member?', 'This will hide the member from active lists.')
            ->authorize(fn($record) => auth()->user()->can('archive', $record))
            ->action(function ($record) {
                $record->archive();
                Architect::toast()->success('Member archived.')->send();
            });
    }
}
MethodDescription
label(string)Button label.
icon(string)Icon class.
color(string)Button colour: 'primary'|'secondary'|'danger'|'warning'|'success'.
destructive(bool)Mark as destructive (renders in danger colour with extra warning).
requiresConfirmation(bool|string $title, string $body)Show a confirmation dialog before running. Pass a string as the first arg to set the dialog title.
authorize(Closure)Authorization callback. Receives the record; return bool.
action(Closure)The action callback. Receives the record and optional form data.
modelClass(string)Eloquent model class used to resolve the record by ID.

Built-in Action Classes

ClassDescription
DeleteActionSoft-deletes the record. Confirmation required by default.
ForceDeleteActionPermanently deletes. Requires explicit destructive confirmation.
RestoreActionRestores a soft-deleted record.
ReplicateActionDuplicates the record.
CreateActionOpens a create form modal.
EditActionOpens an edit form modal for the current record.
ViewActionOpens a read-only content panel for the current record.
ProceduralActionCustom action with a closure — use for one-off operations.

ActionBuilder

use Entelechy\Architect\Actions\ActionBuilder;

$actions = ActionBuilder::make()
    ->add(EditAction::class)
    ->add(DeleteAction::class)
    ->add(ArchiveMemberAction::class)
    ->build();

Rendering

<x-architect :definition="$actions" />

<!-- Or inline with the model being acted on: -->
<x-architect :definition="$actions" :model="$member" />
