Components & Forms

Content / Entries

Read-only detail panels for displaying structured record data, with 8 entry types and a clean two-column default layout.

Overview

The Content subsystem renders information about a record. Unlike forms (which accept input), content panels are display-only. Use them in "view" modals, record detail pages, and review screens.

use Entelechy\Architect\Content\ContentBuilder;
use Entelechy\Architect\Content\Entries\TextEntry;
use Entelechy\Architect\Content\Entries\ImageEntry;
use Entelechy\Architect\Content\Entries\IconEntry;

$content = ContentBuilder::make()
    ->model($member)
    ->columns(2)
    ->entries([
        TextEntry::make('name')->label('Full Name'),
        TextEntry::make('email')->label('Email'),
        IconEntry::make('status')->label('Status')
            ->icon(fn($v) => $v === 'active' ? 'fas fa-check-circle' : 'fas fa-times-circle')
            ->colour(fn($v) => $v === 'active' ? 'green' : 'red'),
        ImageEntry::make('photo_url')->label('Photo')->circular(),
    ])
    ->build();
<x-architect :definition="$content" />

ContentBuilder API

MethodDescription
ContentBuilder::make()Static factory.
model(mixed)The record (Eloquent model or array) to display.
columns(int)Number of display columns (default: 2).
entries(array)Array of entry objects.
section(string $label, array $entries)Group entries under a labelled section heading.
build()Returns ArchitectContentDefinition.

Entry Types

TextEntry

TextEntry::make('email')->label('Email Address')->copyable();

Plain text value. Supports format(Closure) for custom formatting. copyable() adds a copy-to-clipboard button.

ImageEntry

ImageEntry::make('avatar_url')->label('Avatar')->circular()->size(48);

Renders an <img> tag. circular() rounds the image. size(int) sets width/height in pixels.

IconEntry

IconEntry::make('status')
    ->icon(fn($v) => $v === 'active' ? 'fas fa-check-circle' : 'fas fa-ban')
    ->colour(fn($v) => $v === 'active' ? 'green' : 'gray')
    ->tooltip(fn($v) => ucfirst($v));

Renders a Font Awesome icon. Both icon and colour accept a static string or a closure receiving the raw value.

ColorEntry

ColorEntry::make('brand_colour')->label('Brand Colour');

Renders a colour swatch from a hex/RGB value.

CodeEntry

CodeEntry::make('api_key')->label('API Key')->language('text')->copyable();

Renders the value in a monospace code block with optional syntax highlighting.

KeyValueEntry

KeyValueEntry::make('metadata')->label('Metadata');

Renders a JSON object or PHP array as a definition list of key → value pairs.

RepeatableEntry

RepeatableEntry::make('addresses')->label('Addresses')
    ->entries([
        TextEntry::make('street'),
        TextEntry::make('city'),
    ]);

Iterates over a collection relationship and renders nested entries for each item.

Entry (base)

All entry types extend the Entry base class and share:

MethodDescription
Entry::make(string $key)Static factory. Key is the model attribute.
label(string)Display label.
hint(string)Helper text shown below the value.
permission(string)Hide this entry from users without the permission node.
hidden(bool)Conditionally hide the entry.
format(Closure)Custom value formatter — receives raw value, returns display string.
span(int)Number of grid columns this entry spans.
