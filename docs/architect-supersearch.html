Core Subsystem

Supersearch ⌘K

A command-palette–style search overlay that queries multiple data sources simultaneously, with keyboard navigation and configurable result actions.

Overview

Supersearch opens on ⌘K / Ctrl+K (or a custom shortcut) and fans queries out across registered search sets. Each search set targets an Eloquent model or a navigation menu. Results render as rich cards with icons, badges, meta text, and contextual actions.

Quick Example

use Entelechy\Architect\Facades\Architect;
use Entelechy\Architect\Supersearch\SearchSets\ModelSearchSet;
use Entelechy\Architect\Supersearch\ResultCard;
use Entelechy\Architect\Supersearch\Actions\HrefAction;

$search = Architect::supersearch()
    ->placeholder('Search members, events, activities…')
    ->shortcut('mod+k')
    ->searchSet(
        ModelSearchSet::for(Member::class)
            ->groupLabel('Members')
            ->fields(['name', 'email', 'student_id'])
            ->result(
                ResultCard::make()
                    ->icon('fas fa-user')
                    ->title(fn($m) => $m->name)
                    ->eyebrow(fn($m) => $m->student_id)
                    ->badge(fn($m) => $m->status)
                    ->meta(fn($m) => $m->email)
            )
            ->action(HrefAction::make()->href(fn($m) => route('members.show', $m)))
    )
    ->build();
<!-- In the global application layout: -->
<x-architect :definition="$search" />

SupersearchBuilder API

MethodDescription
Architect::supersearch()Start building a supersearch definition.
key(string)Unique identifier for the Livewire engine component.
placeholder(string)Input placeholder text.
shortcut(string)Keyboard shortcut. Use 'mod+k' for ⌘K/Ctrl+K. Follows Alpine Magic Hotkeys syntax.
searchSet(ModelSearchSet|NavigationSearchSet)Register a data source. Call multiple times for multiple sources.
build()Returns ArchitectSupersearchDefinition.

ModelSearchSet API

ModelSearchSet::for(Member::class)
    ->groupLabel('Members')
    ->fields(['name', 'email'])
    ->driver('fulltext')          // 'like' (default) or 'fulltext'
    ->priority(10)                // higher = shown first in results
    ->limit(5)
    ->permission('members.search')
    ->scope(fn($q) => $q->where('active', true))
    ->result(ResultCard::make()...)
    ->action(HrefAction::make()...);
MethodDescription
ModelSearchSet::for(string $model)Static factory targeting an Eloquent model class.
fields(array)Columns to search against. Supports dot-notation for JSON columns.
groupLabel(string)Section heading in the result list.
driver(string)'like' (default) — LIKE %query%, or 'fulltext' — MySQL fulltext index.
priority(int)Rendering order — higher priority groups appear first.
limit(int)Maximum number of results per search set (default: 5).
permission(string)Permission node checked before this set is searched.
recordPermission(callable)Per-record authorization check.
scope(callable)Additional query scope applied before searching.
result(ResultCard)Configure how results are displayed.
action(SearchAction)Action triggered when a result is selected.

ResultCard API

All accessors accept either a static value or a closure receiving the Eloquent model record.

MethodDescription
ResultCard::make()Static factory.
icon(string|Closure)Icon class prefix (e.g. 'fas fa-user').
iconColour(string|Closure)CSS colour for the icon.
avatar(string|Closure)Image URL for an avatar (shown instead of icon).
eyebrow(string|Closure)Small label above the title (e.g. student ID).
title(string|Closure)Primary result title (required).
badge(string|Closure)Badge pill on the right.
badgeColour(string|Closure)Badge colour name.
meta(string|Closure)Secondary line of info below the title.
timestamp(string|Closure)Timestamp or relative date shown at the right edge.
tags(array|Closure)Tag pills shown below the title.
dim(bool|Closure)Mute/grey-out the result card.

Result Actions

ClassDescription
HrefActionNavigate to a URL when the result is selected.
WireActionCall a Livewire method with the record ID.
DispatchActionDispatch a browser event with the record as payload.
CopyActionCopy a value (e.g. email address) to the clipboard.
EmailActionOpen the user's mail client with mailto:.
PhoneActionOpen tel: link.
DownloadActionTrigger a file download.
OpenTabActionOpen a workspace tab for the record.
PanelActionOpen a slide-over panel with a Blade partial.
ConfirmActionShow a confirmation dialog before running the underlying action.
ChainActionRun multiple actions in sequence.

NavigationSearchSet

Search across navigation menu items (registered routes/links). Useful for letting users jump to any page without remembering its location.

use Entelechy\Architect\Supersearch\SearchSets\NavigationSearchSet;

Architect::supersearch()
    ->searchSet(NavigationSearchSet::make()->groupLabel('Pages'))
    ->build();
