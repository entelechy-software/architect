Core Subsystem

CRUD Tables

Sortable, searchable, filterable data tables backed by any Eloquent query, with full create / edit / view / delete modal flows.

Overview

The CRUD Table subsystem is built around three classes:

  • TableBuilder — fluent configuration API
  • ArchitectTableDefinition — value object produced by the builder
  • TableEngine — Livewire component that renders the table

You always extend ArchitectTableDefinition and call builder methods inside definition():

use Entelechy\Architect\Table\ArchitectTableDefinition;

class MembersTableDefinition extends ArchitectTableDefinition
{
    public function definition(): static
    {
        return $this
            ->title('Members')
            ->model(Member::class)
            ->columns([...])
            ->fields([...]);
    }
}

TableBuilder API

All methods return self for chaining.

Column API

use Entelechy\Architect\Table\Column;

Column::make('email')
    ->label('Email Address')
    ->searchable()
    ->sortable()
    ->badge()
    ->colors(['active' => 'green', 'inactive' => 'gray']);
MethodDescription
Column::make(string $key)Static factory. Key maps to the model attribute or query alias.
label(string)Display label in the table header.
searchable(bool)Include this column in the search query.
searchColumns(array)Override which DB columns are searched (for aliased or joined columns).
sortable(string|bool $dir, ?int $priority)Allow sorting. Optionally set default direction ('asc'/'desc') and sort priority.
badge(bool)Render the cell value as a coloured badge.
colors(array)Map values to colour names: ['active' => 'green'].
visibleTo(string $node)Hide column from users without the given permission node.
filter(ArchitectFilter)Attach an inline filter to this column.
type(string)Column render type: 'text', 'date', 'datetime', 'money', 'boolean', 'image', 'link', 'list'.
editAs(string $key)Alias: when editing, use this field key instead of the column key.
options(array)Map of stored values to display labels.
source(string $url)Remote JSON source URL for lookup / autocomplete columns.
visibleWhen(string $field, string $op, mixed $value)Alpine-powered conditional column visibility.
toggleable(bool)Allow user to show/hide this column via the column picker.
model(string)Eloquent model class for inline relationship lookups.
cascadeFrom(string $parentKey)Cascade-filter this lookup from a parent column's value.
labelUsing(callable)Custom callback to format the display label from the raw value.

DateRangeFilter::make('created_at')->label('Date Joined'),

ClassDescription
SelectFilterSingle-value dropdown filter.
MultiSelectFilterMulti-value filter with checkboxes or tag pills.
MultiTagFilterLike MultiSelectFilter but displays as a tag list.
TextFilterFree-text filter against a specific column.
RadioFilterInline radio group filter.
DateRangeFilterFrom / To date range picker.
LookupFilterAsync lookup filter with remote source.

DataModel

For advanced query customisation, create a DataModel class instead of using ->model(Member::class):

use Entelechy\Architect\Table\AbstractEloquentDataModel;

class MemberDataModel extends AbstractEloquentDataModel
{
    protected string $model = Member::class;

    public function getQuery(): \Illuminate\Database\Eloquent\Builder
    {
        return Member::query()
            ->with('union')
            ->where('tenant_id', tenant()->id);
    }
}
// Register in definition:
->dataModel(MemberDataModel::class)

Rendering

// Controller:
public function index(): View
{
    return view('members.index', [
        'definition' => (new MembersTableDefinition())->definition(),
    ]);
}

// Blade:
<x-architect :definition="$definition" />

<x-architect definition-class="\App\Modules\Members\Components\Tables\MembersTableDefinition" />
